Slash commands

← Agent OS

Built-in Claude Code commands plus every Claude and Codex skill you've installed. Codex skills start with $, the way you mention them in Codex. Type what you want to do, like "shrink context", "review my diff" or "make a video". Click a card to copy the command.

Claude skills are read from ~/.claude/skills, ~/.claude/commands and enabled plugins; Codex skills from ~/.codex/skills and ~/.agents/skills; project skills from .claude/skills and .agents/skills in every project you've opened in Claude Code or Codex each time Agent OS collects (every minute). Commands tagged Terminal only open a dialog that the desktop app's Code tab doesn't show, so run them from claude in a terminal.
